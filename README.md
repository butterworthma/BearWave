# BearWave

This repository collects the implementation artifacts for the BearWave system.

## Contents

- `control-node/` - Raspberry Pi control-node dashboard, JS8Call/SparkSDR/QSSTV helper configuration, image watcher, startup services, and setup documentation.
- `remote-node/` - Raspberry Pi Zero remote-node application, boot-cycle service, SSTV capture/encode/transmit scripts, ESP32 supervisor code, and the remote-node hardware design material.

The paper source has deliberately been moved out to `BearWave_Papers` so this repository can remain focused on the deployable system code, hardware files, and operator setup notes.
